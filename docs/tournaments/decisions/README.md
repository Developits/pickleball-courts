# Decision records

Canonical pending decisions are D-01–D-12 in [PRD.md](../../../PRD.md).
No pending recommendation is accepted merely because it has a record.
Phase 1 decisions D-01–D-04 are recorded in
[D-01-D-04-phase-1.md](D-01-D-04-phase-1.md).

After the owner confirms a decision, record:

- Decision ID, date, approving owner and conversation/PR reference.
- Approved choice and alternatives rejected.
- Effect on approved business-rule IDs.
- Required changes to each of the four specifications.
- Implementation phase and tests affected.

Do not copy secrets or private registration data into decision records.
Do not independently redefine the permission/state contract in this directory.
